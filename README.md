# Spotify Album Poster

Generate print-style album posters from a Spotify album link: exact title/artist/tracklist from Spotify's embed page, release date + hi-res 1600px cover from iTunes.

## Run

    python3 server.py            # port 8888
    python3 server.py 9000       # custom port

Then open http://127.0.0.1:8888/ and paste a Spotify album URL. No API keys needed.
